# AGENTS.md

Guidance for AI coding agents working in this repository.

## Project overview

**apkforge** automatically downloads stock Android apps, applies [Morphe](https://github.com/MorpheApp) patch bundles, signs them, and publishes daily GitHub releases. It also mirrors unpatched stock APKs. Builds run via GitHub Actions cron; locally it is driven by `main.py`.

- Language: Python 3.13+, managed with **uv**
- License: **GNU GPLv3** — every source file must keep its original copyright header (`Copyright (C) 2026 softpyscho ... DO NOT REMOVE OR ALTER THIS COPYRIGHT HEADER`)
- Repo: https://github.com/softpyscho/apkforge

## Commands

```bash
uv sync                                              # install deps (creates .venv)
uv run main.py                                       # build all enabled apps
uv run main.py SomeApp                               # build one app (config.toml table name)
uv run main.py SomeApp arm64-v8a                     # build with arch override
uv run main.py clear                                 # delete build/, temp/, build.md, build.json
uv run python -m unittest discover -s tests -t . -v  # unit tests
uvx ruff@0.16.7 check .                              # lint
```

Run lint and tests before finishing any change. Lint config lives in `pyproject.toml` (`ruff`, rules: E, F, B, I, UP, RUF, SIM, C4, PTH, G, PIE; E501 ignored).

## Project layout

```
main.py                  # CLI entrypoint
config.toml              # per-app build config (pkg, arch, dl urls, patches, patcher-args)
src/core/                # builder, config, logger, network, patcher, prebuilts, versions
src/scrapers/            # APKMirror, Uptodown, GitHub, Direct + shared base
src/scripts/             # CI helpers: matrix, logs, readme, telegram, wa_version
tests/                   # unittest suite
docs/                    # ARCHITECTURE.md, ROADMAP.md
.github/workflows/       # ci.yml (build), lint.yml (ruff + tests + README sync), cleanup.yml
```

## Conventions

- Match existing style; imports are sorted by ruff (`I` rules) — use `from src.core...` absolute imports.
- Add no comments unless the surrounding code requires them; keep the copyright header untouched.
- New apps are added by editing `config.toml` (see CONTRIBUTING.md → "Adding an app or patch source"); the README app table is auto-generated by `src/scripts/readme.py` — do not hand-edit the block between `<!-- APPS_START -->` and the matching end marker.
- Builds require Java 21+ (Morphe CLI) and write to `build/`, `temp/`, `unmodified-apks/` — all gitignored.

## Never touch

- `morphe.keystore`, `.env`, any `*.keystore` / `*.jks` / credentials — secrets, never commit or print.
- Generated outputs: `build/`, `temp/`, `unmodified-apks/`, `build.json`, `build.md`.
- `.github/workflows/` unless the task is explicitly about CI.

## Verification

`uvx ruff@0.16.7 check .` then `uv run python -m unittest discover -s tests -t . -v` must pass. CI runs both on every push/PR touching `src/`, `tests/`, `config.toml` or `pyproject.toml`.
